Universality

Corollary.

The SPE state of the agentic evaluator completion-generates any computable harness.

Every agentic machine whose prompt function and harness procedure are computable can be embedded in the CEK agentic evaluator and reached from a single seed state.

In other words: one fixed program —

let y = lm q in eval y

— allows the model to implement any computable agent loop by choosing the right completion. The embedding is invisible to the model (Thm C.3.3), so the model fully specifies the successor state via its program.
