The Agentic Evaluator

Take a standard program evaluator (the CEK machine) and add a special primitive lm that calls the language model.

Definition. The CEK agentic evaluator observes the CEK machine only at boundary states — states where the next step is to evaluate lm:

let y = lm v in ...

Between boundaries, execution is ordinary deterministic evaluation. The model contributes exactly one completion per transition. The evaluator itself is not a hand-written agent loop — it is the boundary-to-boundary behavior of a generic program evaluator around model calls.
