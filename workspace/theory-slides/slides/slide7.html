SPE States

Definition. A state x is an SPE state of X if (X, x) completion-generates X itself. From one state, the model can reach an embedded copy of any state of the machine.

Theorem C.5.2. The CEK agentic evaluator contains an SPE state.

The seed state is produced by evaluating:

let y = lm q in eval y

Ask the model for a completion y, then evaluate y as code. Whatever program the model returns becomes the next computation. Since any boundary state can be loaded by evaluating a suitable quotation, one completion from this seed reaches every state of the evaluator.
