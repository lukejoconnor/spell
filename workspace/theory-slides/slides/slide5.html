Completion-Generation

Definition C.3.6.

A state xseed of X completion-generates X′ if there exists an embedding e of X′ in X such that every embedded state is reachable via some completion:

∀ s′ ∈ S′ : ∃ c ∈ C : h(xseed, c) = e(s′)

One completion from a fixed seed state can “load” any state of the target machine into the ambient machine.
