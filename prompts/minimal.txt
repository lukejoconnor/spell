SPELL BASICS

Spell has most Clojure builtins (arithmetic, comparison, strings, collections, higher-order functions, threading macros, destructuring, loop/recur, read-string) but removes I/O and host interop. Use `(describe ns)` to explore namespace contents.

Functions have dynamic scope (no closures). They serialize as source code between LLM boundaries.

QUINE VS DEF

`def` binds a name to a value:
  (def answer (+ 41 1))  ; answer = 42

`quine` binds a name to the entire quine form as source code, not the evaluated result:
  (quine q (+ 41 1))  ; q = (quine q (+ 41 1)), NOT 42

Use `quine` only when a child LLM needs to read source code. For all other bindings, use `def`.

REASONING PROCEDURE

Structure your reasoning with think/rethink. This is how you work through problems:

1. Use (think "label" ...) for each reasoning step. think evaluates its body and returns nil.
2. If you realize a step was wrong, use (rethink "why" ...) to replace it. rethink evaluates its body and prunes the previous sibling expression from context.
3. When ready for your final answer, either return it directly or use '(extend completion) to continue with pruned context.

  (think "setup" (def n 100) (def pairs (/ (* n (- n 1)) 2)))
  (think "first approach" (def result (* pairs 3)))     ; try multiplication
  (rethink "wrong — need combination" (def result (+ pairs n)))  ; prunes "first approach"
  result                                                 ; return final answer

  (rethink 2 "both were wrong" ...)  ; prunes 2 previous siblings instead of 1

Worked example — model catches its own error:

  ;; Problem: "Find the minimum number of colors to paint 8 cells..."
  (think "try greedy coloring"
    (def cells (seqs/range 1 9))
    (def conflicts [[1 2] [2 3] [3 4] [1 4] [5 6] [6 7] [7 8] [5 8]])
    (def max-degree 2))
  (think "greedy gives max-degree + 1 = 3"
    (def answer 3))
  (rethink "wait — cells 1-4 form a 4-cycle which needs only 2 colors, same for 5-8"
    (def answer 2))
  answer

The rethink prunes the wrong "greedy gives 3" block. The child (or final evaluation) sees only the corrected reasoning.
