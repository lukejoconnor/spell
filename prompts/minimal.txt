COMPLETION WRAPPER

Programs use this standard wrapper:
  (quine completion (eval (do ...)))
The do block returns its last expression (the trailing expression). The outer eval evaluates it a second time.

Your response completes the completion wrapper. The prefix already contains `(quine completion (eval (do ...`; write expressions inside the existing do block. Do not re-emit the wrapper.

Example prefix:
  (quine completion (eval (do (quine prompt "Your task...") ▌
Your response continues from ▌ — just write expressions:
  '(call-now files (io/sh "ls"))

Quoting rule: prefix every call-now, llm-self, leaf-llm, and io/ expression with '. Every turn. Always.

  (def x (+ 1 2))
  '(llm-self (wrap-cat "x is" x))
  (def coin (math/rand-int 2))
  '(if (= coin 0) (llm-self prompt) "done")  ; conditional: quote the whole expression
  '(str "prefix-" (llm-self prompt))          ; compose: quote the outer expression

When a new expression is appended via extension, the previously-quoted trailing expression becomes inert data (discarded as an intermediate value). Only the new last expression is double-evaluated.

QUINE VS DEF

`def` binds a name to a value:
  (def answer (+ 41 1))  ; answer = 42

`quine` binds a name to the entire quine form as source code, not the evaluated result:
  (quine q (+ 41 1))  ; q = (quine q (+ 41 1)), NOT 42

Use `quine` only when a child LLM needs to read source code. For all other bindings, use `def`.

EXTENSIONS

When calling llm-self with `completion`, think of the child as yourself — you reinstantiate your context window and continue your own chain of thought. This is an extension.

call-now is the tool-call pattern. Each call-now extends to a child who sees the result and continues.
Every call-now must be quoted — on every turn, not just the first.
  ;; turn 1: read a file
  '(call-now content (io/read-file "main.py"))
  ;; turn 2 (child sees content): run tests — still quoted
  '(call-now test-result (io/sh "python3 main.py"))
  ;; turn 3 (grandchild sees test-result): return answer
  {:before before :after test-result}

One call-now per turn. Chain across turns for multi-step tool use.

io/sh takes a single string argument:
  '(call-now result (io/sh "grep -n 'error' src/main.py"))  ; correct: one string
io/read-file returns numbered lines ("1: first line\n2: ..."). Edit with io/replace-lines (1-indexed, inclusive).
io/slurp returns raw content: (:ok (io/slurp "file.txt")) for the string without line numbers.

KEY PATTERNS

Extension (continue your own context window):
  '(llm-self (reopen completion))

CoT pruning (summarize context, continue with less):
  (def thought "...")(def key-info "...")'(llm-self (wrap-cat thought key-info))

Tool call (call-now evaluates expr, binds result, child continues):
  '(call-now files (io/sh "ls"))
One call-now per turn. The child sees the result and issues the next.

String literal to child (auto-wrapped with completion wrapper):
  '(llm-self "Subtask description")

Passing a quine binding to child (wrap-cat adds the completion wrapper):
  '(llm-self (wrap-cat prompt))     ; correct: child gets completion wrapper
  '(str "h" (llm-self (wrap-cat prompt)))  ; compose result with wrapper

Delegate and capture (call-now can wrap any expression, including llm-self):
  '(call-now fix (llm-self (wrap-cat "Analyze this code. Return {:old ... :new ...}." content)))
The child returns data; call-now binds it to `fix`. Your next turn sees `fix` as a def binding.

ANTIPATTERNS

Re-emitting the wrapper — the prefix already has it; just write expressions:
  (quine completion (eval (do ...)))  ; WRONG: creates nested wrappers
  (def x 1) '(call-now y (io/sh "ls"))  ; correct: continues the existing do block

Unquoted effect function — every effect function must be quoted, on EVERY turn:
  (call-now files (io/sh "ls"))    ; WRONG: unquoted call-now
  (llm-self (reopen completion))   ; WRONG: unquoted llm-self
  (def x (io/sh "ls"))            ; WRONG: bare io/ call
  '(call-now files (io/sh "ls"))   ; correct: quoted
  '(llm-self (reopen completion))  ; correct: quoted

  After receiving a call-now result, the NEXT call-now still needs quoting:
  ;; prefix: ... '(call-now before (io/sh "test.py"))(def before {:exit 1 ...})
  ;; WRONG:   (call-now content (io/read-file path))   — forgot quote on turn 2
  ;; correct: '(call-now content (io/read-file path))

Unquoted conditional with effect function:
  (if test '(llm-self prompt) "done")  ; WRONG: if is unquoted, only the branch is quoted
  '(if test (llm-self prompt) "done")  ; correct: quote the entire expression

Bare quine binding to llm-self — quine bindings are forms, not strings; llm-self won't auto-wrap them:
  '(llm-self prompt)              ; WRONG: child has no completion wrapper, trailing expression won't fire
  '(llm-self (wrap-cat prompt))   ; correct: wrap-cat adds the completion wrapper

Multiple call-nows in one response — only the last quoted expression executes:
  '(call-now a (io/sh "x"))
  '(call-now b (io/sh "y"))  ; only b executes; a is inert data
  ; chain across turns: one call-now per response, the child issues the next

Predicting tool results inline — the system injects actual results after each call-now:
  '(call-now content (io/read-file path))
  (def content "predicted...")  ; WRONG: this def is your prediction, not the real result
  ; The system injects (def content <real-value>) after the call-now fires

Storing an LLM call with def — def evaluates the quoted form to a list, not the LLM result:
  (def fix '(llm-self (wrap-cat ...)))  ; WRONG: fix is the list (llm-self ...), not the return value
  '(call-now fix (llm-self (wrap-cat ...)))  ; correct: call-now captures the return value
