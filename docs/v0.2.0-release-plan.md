# Spell v0.2.0 Release Checklist

**Status:** final release-preparation checklist
**Release intent:** first public-facing software release of Spell.
**Target integration branch:** `v0.2.0-dev`

Spell v0.2.0 should present the repository as an experimental,
CLI-first implementation of self-programmed execution. The release assumes
a paid or authenticated LLM provider for normal use; the no-cost `--test`
provider remains an installation smoke test. v0.1.0 remains the
paper/reproducibility-oriented release, while v0.2.0 is the first release
focused on making the repository readable, presentable, and usable as
software.

API design, Python adapter design, and API documentation were integrated
separately from the release-surface cleanup.

## Final Release Checks

Before cutting or merging the integrated v0.2.0 release branch:

- [ ] Run CLI smoke checks:
  - `bin/spell -h`
  - `bin/spell -t "Return a short greeting"`
- [ ] Run fast tests:
  - `clj -M:test-fast`
- [ ] Run retained benchmark API tests while that API remains in the archive:
  - `clj -M:test -n spell.benchmark-api-test`
- [ ] Check patch hygiene:
  - `git diff --check`
- [ ] Inspect the tracked archive surface:
  - `git archive --format=tar HEAD | tar -tf - | sort`
- [ ] Confirm the archive contains no tracked `notebook/` files.
- [ ] Confirm the removed GCP and paper benchmark scripts are absent.
- [ ] Search public docs and examples for stale private/research wording:
  - `rg -n "benchmark|paper|reviewer|notebook|GCP|CLAUDE|NeurIPS|reproduc" README.md AGENTS.public.md docs examples config test`

Intentional remaining hits should be limited to public-facing references such
as the README paper link, v0.1.0 reproducibility notes, API docs' benchmark
adapter wording, and test/source names where the runtime code remains
intentionally in scope.
